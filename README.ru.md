# Трекер Задач Предприятия (Enterprise Task Tracker)

Профессиональное приложение для управления задачами корпоративного уровня. Реализовано по классической N-Tier (многоуровневой) архитектуре, демонстрируя надежную интеграцию между современным фронтендом (SPA - Single Page Application) и RESTful бэкендом.

## 🌟 Обзор
Этот проект представляет собой высокопроизводительный аналог ведущих корпоративных систем управления задачами (таких как Jira или Trello) с особым акцентом на бизнес-логику, премиальный дизайн и масштабируемую архитектуру.

* **Фронтенд**: Angular 17+, Angular Material, CSS Grid/Flexbox UI.
* **Стейт Менеджмент**: **NgRx** (Redux) для Undo/Redo истории.
* **Бэкенд**: ASP.NET Core 8 Web API.
* **База данных**: SQLite (через Entity Framework Core).
* **Real-Time**: **SignalR** (WebSockets) для мгновенной синхронизации (коллаборативность).
* **Специальная возможность**: Lightweight Content Explorer (кастомный дашборд активности) и интеграция с Jira API.

## 🔥 Killer Features (Для Портфолио)
1. **Undo/Redo Engine**: Управление сложным состоянием реализовано через **NgRx**. Это позволяет перемещать задачи и мгновенно отменять действие (<kbd>Ctrl+Z</kbd> паттерн).
2. **Real-Time Collaboration Dashboard**: Благодаря **SignalR**, изменения мгновенно отображаются у всей команды без перезагрузки страницы (как в современных "Shared Whiteboards").
3. **Lightweight Content Explorer**: Глубокая стилизация (Glassmorphism, Dark mode, CSS Grid) для виджета ленты активности.
4. **Professional Git Flow**: Коммиты оформлены в стиле **Conventional Commits** (feat, fix).
5. **Чистая Архитектура**: Dependency Injection, Repository Pattern.

## 🏗️ Архитектура

1. **Слой представления (Фронтенд)**: 
   - Использует Angular Material для UI-компонентов корпоративного класса.
   - Реализует Angular CDK для функционала перетаскивания (drag-and-drop) на Kanban-доске.
   - Опирается на `RxJS` для обработки асинхронных потоков данных.
   - Имеется автоматический перехватчик (Interceptor) JWT для безопасного взаимодействия с API.

2. **Слой API и бизнес-логики (Бэкенд)**:
   - Написан на C# с использованием последних абстракций ASP.NET Core.
   - Защита эндпоинтов реализуется через JWT (JSON Web Tokens) авторизацию.
   - Следует принципам DTO (Data Transfer Objects), чтобы избежать избыточной передачи данных.
   - Предоставляет чистые маршруты RESTful, документированные в Swagger.

3. **Слой доступа к данным**:
   - Построен на Entity Framework (EF) Core по принципу Code-First.
   - Обеспечивает корректные связи (связь "один ко многим" между проектами и задачами, привязка владельцев).

## 🚀 Как это работает и как использовать

Для работы приложения необходимо одновременное функционирование **бэкенда** и **фронтенда**.

### 1. Запуск Backend API
Бэкенд является источником истины (Source of Truth) и управляет базой данных.
1. Откройте терминал (командную строку) и перейдите в папку `Backend`:
   ```bash
   cd Backend
   ```
2. Соберите и запустите ASP.NET Core проект:
   ```bash
   dotnet run
   ```
3. API будет запущен (обычно на `http://localhost:5031` или `https://localhost:7081`).
   - *Для проверки откройте в браузере `http://localhost:5031/swagger` для просмотра автосгенерированной документации.*

### 2. Запуск Frontend SPA
Фронтенд использует Angular CLI для запуска интерактивного веб-приложения.
1. Откройте **новый** отдельный терминал и перейдите в папку `Frontend`:
   ```bash
   cd Frontend
   ```
2. Установите npm-зависимости (если еще не сделали этого):
   ```bash
   npm install
   ```
3. Запустите сервер разработки Angular:
   ```bash
   npm start
   ```
4. Откройте браузер по адресу `http://localhost:4200`.

### 3. Рабочий процесс в приложении

1. **Аутентификация**: При загрузке фронтенда для начала выберите **Register** (Регистрация), чтобы создать новую учетную запись.
2. **Панель (Dashboard)**: После входа в систему вы попадете на Дашборд проектов. Нажмите **NEW PROJECT** (Новый проект) для создания рабочего пространства.
3. **Доска задач (Task Board)**: Кликните по созданному проекту, чтобы войти в канбан-доску.
   - Нажмите **ADD TASK** (Добавить задачу), чтобы внести задачу вручную.
   - **Перетаскивание**: Свободно перемещайте задачи между колонками *To Do*, *In Progress*, *Review* и *Done*.
4. **Интеграция с Jira**: Находясь на доске задач, нажмите **IMPORT JIRA**. Введите ваш домен Atlassian, почту учетной записи, API Token и Ключ Проекта (например, *KAN*), чтобы массово импортировать тикеты в вашу локальную базу данных.
